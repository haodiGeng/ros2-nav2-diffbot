# M7 累计定位偏差排查与校准

## 结论

本轮将误差分为里程计转角误差、地图定位误差和导航到点容差。发现当前仿真存在约 0.5% 的有效轮距偏差；校准后再降低 AMCL 运动噪声参数，两轮闭环的最大同步定位位置差分别为 9.30 cm、6.50 cm，原配置本轮基线为 13.83 cm。两轮各四个导航目标均成功，恢复次数为零。

这是当前仿真场景的有限重复测试，不能推广为真实机器人精度保证，也不能认为累计偏差已完全消除。

## 测量方法

每个实验从新仿真开始，使用同一解析地图和场景。直线往返、正反向旋转、四目标闭环分别测试。闭环目标为 (0, 2.6)、(0, 0)、(3.3, 0)、(0, 0)，过程不重置定位。

以仿真真值时间戳查询 map→base_footprint 和 odom→base_footprint；odom 只用初始位姿作一次固定 SE(2) 对齐，不拟合整条轨迹。运动阶段所有记录均有对应 TF。真值仅用于记录、误差分析和越界中止，没有输入 AMCL 或导航控制作为定位反馈。

记录包含真值、odom、AMCL、同步 TF、配置及模型快照。数据位于 `artifacts/m7_localization/`，汇总见 `summary.json`，脚本为 `localization_study.py` 和 `analyze_localization.py`。

## 分离出的因素

1. 原轮距配置下，一圈 odom 转角约 6.2832 rad，真值约 6.3143 rad，差约 1.8°。保持轮子几何中心间距 0.40 m，单独将驱动插件有效轮距乘以 0.995，得到 0.398 m，转角差降至约 0.03°。默认比例仍为 1.0。
2. 单独校准轮距未改善全部地图定位误差，说明不能把问题都归于轮距。
3. 可选配置将 AMCL alpha1～alpha4 从 0.01 调为 0.001，alpha5 不变。低噪声仿真里取得改善；真实机器人存在打滑和传感器噪声，不能照搬。
4. 目标 xy 容差仍为 0.12 m。世界坐标到目标的误差，同时包含定位偏差和估计坐标下允许的到点误差。例如基线一次返回，真实距目标 19.43 cm，估计距目标 8.05 cm，真值与估计相差 11.58 cm。这几个距离不能直接相加，原始记录保存了向量分解。

## 对比结果

下表是同步 map TF 与世界真值的位置差，不是最终到点误差。

| 配置 | 闭环最大差 / cm | 闭环 P95 / cm |
|---|---:|---:|
| 原配置 | 13.83 | 12.42 |
| 仅轮距校准 | 17.75 | 15.96 |
| 轮距校准 + sigma_hit=0.05 | 20.93 | 16.52 |
| 轮距校准 + likelihood_field_prob，第 1 轮 | 32.56 | 21.80 |
| 同上，第 2 轮 | 19.05 | 17.55 |
| 轮距校准 + 较低运动噪声，第 1 轮 | 9.30 | 7.14 |
| 同上，第 2 轮 | 6.50 | 4.35 |

较低运动噪声配置补测：直线最大位置差 0.34 cm，旋转最大位置差 0.78 cm。两轮闭环最终世界坐标到点误差约 9.64 cm、10.48 cm。未采用效果不稳定的激光模型候选。AMCL 带随机性，当前样本量不足以证明统计显著性。

```bash
source /opt/ros/humble/setup.bash
source ~/nav_ws/install/setup.bash
ros2 run my_robot_navigation start_calibrated_navigation.sh
```

已检查新增入口 shell 语法，三个相关包编译成功，`--show-args` 参数解析成功；这些检查不代表新的 GUI 演示验收。

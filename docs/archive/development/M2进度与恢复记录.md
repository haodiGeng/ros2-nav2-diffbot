## 启动注意事项

本轮节点统一使用 `ROS_DOMAIN_ID=22`。新的查看或控制终端需要先执行下面两条。

```bash
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=22
```

Gazebo 无 GUI 启动时，必须把世界文件加入 `gz_args`。只传 `-s -r` 会覆盖原世界参数，导致空世界。

```bash
tb4_share="$(ros2 pkg prefix --share turtlebot4_ignition_bringup)"
LIBGL_ALWAYS_SOFTWARE=1 ros2 launch turtlebot4_ignition_bringup \
  turtlebot4_ignition.launch.py model:=lite world:=warehouse rviz:=false \
  gz_args:="-s -r $tb4_share/worlds/warehouse.sdf"
```

SSH 启动需要采用当前桌面的 DISPLAY 和 XAUTHORITY。授权路径可能随登录变化，应从桌面进程环境读取。启动器退出后应检查 Gazebo 子进程是否仍存活，重复实例会干扰时钟和 TF。

Ubuntu 本轮运行日志位于 `~/nav_ws/artifacts/m2/logs/`，导航和定位日志分别是 `navigation.log` 与 `localization.log`。

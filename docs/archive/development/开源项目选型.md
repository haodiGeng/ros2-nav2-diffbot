# ROS 2 导航开源项目初选

核查日期为 2026-11-19。当前环境为 Ubuntu 22.04、ROS 2 Humble、Gazebo Fortress、VMware 软件渲染。此轮完成仓库文档和部分源码核对，候选尚未在本机实测。

## 第一候选 BCR Bot

仓库为 https://github.com/blackcoffeerobotics/bcr_bot/tree/ros2 ，许可证为 Apache-2.0。

README 明确包含 Humble + Fortress 安装、`ign.launch.py` 仿真、`mapping.launch.py` 建图和 `nav2.launch.py` 导航流程。提供相机、双目和 2D 激光开关。首轮拟关闭相机和双目，只启用 2D 激光，在简单场景中做基线测试。

需要验证消息命名空间、里程计来源、仿真时间配置及无窗口启动。默认示例采用 world 里程计，正式实验要记录该选择，并在需要时切换到轮式里程计。切换仓库无法自动消除 VMware 的 Mesa 渲染问题。

## 备选 Linorobot2

仓库为 https://github.com/linorobot/linorobot2/tree/humble 。Humble 分支的 `linorobot2_gazebo/launch/gazebo.launch.py` 实际调用 `gazebo`、`gazebo_ros` 和 `spawn_entity.py`，属于 Gazebo Classic。虽然包组织适合自建底盘，采用该分支需要额外安装 Classic 或迁移仿真配置。许可证文件需在正式引入时再次读取。

## 参考 ROS2_Autonomous_Robot

仓库为 https://github.com/alizabun/ROS2_Autonomous_Robot ，页面标注 Apache-2.0。README 声明支持 Humble/Fortress，包结构覆盖模型、控制、SLAM 和 AMCL。其列出的启动层级主要覆盖建图及定位，完整导航执行还需进一步核对源码，因此作为结构参考。

## 采用步骤

1. 在独立候选工作空间获取 BCR Bot 的 ros2 分支，记录提交 SHA 与许可证。
2. 静态核对实际启动参数和依赖，再构建。候选目录与现有 TurtleBot 工作空间分开。
3. 用简单场景验证时钟、激光有效范围、TF、速度控制和运行速度。
4. 验证建图、保存地图、AMCL 和绕障到点后，确定为项目基线。
5. 逐项加入自己的模型、场景、A* 插件及评测脚本。
